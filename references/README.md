# references/ — referências visuais de estudo (só local)

Esta pasta **não é versionada** (veja `.gitignore`). Ela guarda capturas de
tela, fotos, moodboards e anotações usadas para estudar estilo. O conteúdo
nunca vai para o build do jogo.

Não coloque aqui arquivos extraídos de jogos comerciais (malhas, texturas,
sons). Veja `docs/assets/REFERENCIAS.md`.

Subpastas: personagens, armas, mochilas_acessorios, construcoes, cenario,
baus_coletaveis, texturas_materiais, animacoes.
